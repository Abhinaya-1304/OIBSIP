# Customer Segmentation Analysis

## Project Overview

This project analyzes customer purchasing behaviour using the Online Retail dataset and groups customers into segments using K-Means clustering.

## Objective

To identify customer groups based on purchasing behaviour and support targeted marketing strategies.

## Tools Used

* Python
* Google Colab
* Pandas
* Scikit-learn
* Matplotlib
* Seaborn

## Project Steps

1. Loaded and explored the dataset.
2. Cleaned missing customer IDs, cancelled invoices, and invalid purchase records.
3. Calculated Recency, Frequency, and Monetary (RFM) values.
4. Standardized the RFM features.
5. Used the Elbow Method to help select the number of clusters.
6. Applied K-Means clustering.
7. Visualized and saved the customer segmentation results.

## Output Files

* `customer_segments.csv`
* `customer_segment_summary.csv`
* Google Colab notebook
* Screenshots of graphs and results

## Conclusion

This project demonstrates how customer purchasing data can be analyzed using RFM analysis and K-Means clustering to identify different customer segments.
